# Internationalization (i18n)

## Setup

- Library: `i18next` v22 + `react-i18next` v12
- Languages: English (`en`), Portuguese (`pt`)
- Translation files: `/client/public/i18n/{lng}.json`
- Language is detected from browser, persisted in `localStorage` under key `lang`
- Language selector available in the StatusBar (inside the game room)

## Translation Structure

```
{
  "global":        → App-wide strings (errors, nav labels)
  "global_fields": → Form field labels and placeholders
  "views":         → Page-specific strings (join, new, room)
  "log":           → Game log messages (server-generated, displayed in chat)
  "game":          → In-game UI strings
  "chat":          → Chat-specific strings (whisper tags, target labels)
  "components":    → Component-specific strings (chat input, player card, connection)
  "rules":         → Game rules text
}
```

## Pluralization

Uses i18next `_one`/`_other` suffixes:

```json
"coins_one": "{{count}} coin",
"coins_other": "{{count}} coins"
```

## Adding a New Language

1. Create `/client/public/i18n/{code}.json` with the same key structure.
2. Add the language to `LANGUAGES` in `/client/src/lib/constants.ts`.
3. The language will automatically appear in the StatusBar selector.
