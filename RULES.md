## Coup Rules

### Setup

3 - 10 players

if 3 - 6 players -> 3 cards / character (15)
if 7 - 8 players -> 4 cards / character (20)
if 9 - 10 players -> 5 cards / character (25)

2 cards per player
player can see its own cards

### Game

player
1/4 actions

- income -> get a coin
  - cant be blocked
- foreign_aid -> get two coins
  - can be blocked by "duke"
- coup
  - pay 7 coin to bank (always this cost)
  - choose a player to loose an influence
    - flip that card, and it looses it effect.
  - if player coin is >= 10 this action is mandatory
- character_action
  - say you have that character
    - wait for contestation
      - if false ("bluff")
        - player looses one of it influences
      - if true
        - who contested looses one of it influences
        - player can choose a new card to replace the exposed one
  - duke
    - action
      - get 3 coin
    - contrary action
      - block other players to take foreign_aid
    - can't be blocked
  - captain
    - action
      - extort other player. theft 2 coins
    - contrary action
      - block other player to theft
  - killer
    - action
      - pay 3 coins and take an influence
  - CONTESSA
    - action
      - block killer
    - can't be blocked
  - ambassador
    - action
      - get 2 more cards
        - see all of 4 and choose 2 cards.
    - contrary action
      - block captain on extortion
- optional character
  - inquisitor
    - actions
      - replaces ambassador
        - get 1 more cards
          - see all of 3 and choose 2 cards.
        - investigate
          - get a player card, review it, and ask to replace it
    - contrary action
      - block captain on extortion
- until one player with any influence
